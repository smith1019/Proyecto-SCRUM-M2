# Product Backlog

## Épica 1: Gestión de cuenta y acceso
### Feature 1.1: Registro
- US-01: Como afiliado nuevo, quiero registrarme en la app con mis datos básicos, para poder acceder a los servicios digitales de la EPS.

### Feature 1.2: Inicio de sesión
- US-02: Como afiliado registrado, quiero iniciar sesión con mi usuario y contraseña, para acceder a mi cuenta de forma segura.

### Feature 1.3: Recuperación de contraseña
- US-03: Como afiliado, quiero recuperar mi contraseña si la olvido, para no perder el acceso a mi cuenta.

### Feature 1.4: Actualización de datos personales
- US-04: Como afiliado, quiero actualizar mis datos personales, para mantener mi información de contacto correcta.

## Épica 2: Gestión de citas médicas
### Feature 2.1: Búsqueda de especialidad o médico
- US-05: Como afiliado, quiero buscar por especialidad o médico, para encontrar la atención que necesito.

### Feature 2.2: Agendamiento de citas
- US-06: Como afiliado, quiero agendar una cita médica, para recibir atención sin ir presencialmente a la EPS.

### Feature 2.3: Reprogramación de citas
- US-07: Como afiliado, quiero reprogramar una cita ya agendada, para ajustarla si surge un imprevisto.

### Feature 2.4: Cancelación de citas
- US-08: Como afiliado, quiero cancelar una cita, para liberar el cupo si ya no la necesito.

### Feature 2.5: Historial de citas
- US-09: Como afiliado, quiero ver el historial de mis citas, para llevar seguimiento de mi atención médica.

## Épica 3: Trámites y notificaciones
### Feature 3.1: Certificados
- US-10: Como afiliado, quiero descargar certificados, para presentarlos donde los necesite sin trámite presencial.

### Feature 3.2: Solicitud de autorizaciones
- US-11: Como afiliado, quiero solicitar autorizaciones desde la app, para agilizar mis trámites médicos.

### Feature 3.3: Notificaciones
- US-12: Como afiliado, quiero recibir notificaciones, para no olvidar mis citas ni el estado de mis trámites.

## Épica 4: Consulta de información médica
### Feature 4.1: Consulta de autorizaciones
- US-13: Como afiliado, quiero consultar el estado de mis autorizaciones, para saber si ya puedo continuar con mi trámite.

### Feature 4.2: Consulta de resultados de exámenes
- US-14: Como afiliado, quiero consultar mis resultados de exámenes, para conocerlos sin tener que ir a la sede.

### Feature 4.3: Consulta de historia médica
- US-15: Como afiliado, quiero consultar mi historia médica, para tener acceso a mis antecedentes y diagnósticos.
