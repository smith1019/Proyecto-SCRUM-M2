# Salud360

Aplicación móvil que permite a los afiliados de una EPS realizar sus principales trámites (citas médicas, autorizaciones, certificados, consulta de resultados e historia médica) de forma digital, rápida y segura, sin necesidad de desplazarse a una sede física.

## Organización

El proyecto se desarrolla utilizando la metodología Scrum y se organiza en Sprints.

- `docs/product-backlog.md`: Product Backlog completo del proyecto (épicas, features, historias de usuario).
- `docs/user-stories.md`: detalle de cada historia de usuario (criterios de aceptación, prioridad, estimación).
- `docs/sprints/`: documentación de cada Sprint (Sprint Backlog y Sprint Review).
- `src/`: código fuente del proyecto (cuando corresponda).
